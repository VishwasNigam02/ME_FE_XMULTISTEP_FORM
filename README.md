# XMultistepForm

## Files
- `index.html` — form structure
- `style.css` — desktop and mobile styling
- `script.js` — navigation, validation, plan/add-on selection and totals

## Run in your Crio workspace
Copy these three files into the project root. Keep the existing `assets/images/` directory as supplied by the starter project. Then run the app with Live Server or the workspace's preview.

Before assessment:
1. Deploy the project and put only the deployed URL in `submit.txt` in the project root.
2. Run:
   `chmod +x run_assessment.sh`
   `./run_assessment.sh`
3. Review `assessment_results.json` and fix any failing tests.
